# Excel → PDF с подписью — первая версия

Локальное приложение на Python для Windows с установленным настольным Microsoft Excel.
Выберите XLSX и PNG/JPEG подписи, нажмите «Создать и посмотреть», затем «Сохранить PDF».
Предпросмотр открывается в вашей стандартной программе для PDF.

## Запуск

1. Установите Python 3.11 или новее с python.org (с Python Launcher `py`).
2. Распакуйте всю папку в обычную доступную для записи папку.
3. Один раз запустите `setup.bat`. Для загрузки зависимостей нужен интернет.
4. Запустите `start.bat`.

Для дальнейших запусков достаточно `start.bat`. Excel должен быть активирован и запускаться
без окон первоначальной настройки. Это исходники с установочным скриптом, не готовый EXE.

## Поведение

- Поддерживаются файлы `.xlsx`, один лист за раз. Старый `.xls` сначала сохраните как `.xlsx`.
- По умолчанию берётся первый видимый лист; можно указать точное название другого листа.
- A4, книжная или альбомная ориентация, все столбцы на ширину одной страницы.
- По высоте количество страниц не ограничено: строки не сжимаются до одной страницы.
- Исходная область печати по умолчанию игнорируется, чтобы старое ограничение не обрезало новые строки.
  При необходимости включите соответствующий флажок и проверьте область в Excel.
- Внизу каждой страницы резервируется около 44 мм. Подпись вставляется только на последнюю.
- Подпись справа внизу: отступ справа 15 мм, снизу 16 мм, ширина по умолчанию 45 мм,
  высота не более 22 мм. Пропорции изображения сохраняются.
- Картинка не обрезается и фон не удаляется. Заранее используйте обрезанный PNG с прозрачным
  фоном или аккуратный скан на белом фоне. Большие поля внутри картинки уменьшат саму подпись.
- Подпись не перекрывает существующий текст или графику: при конфликте программа выдаёт ошибку.
- Исходный Excel открывается только для чтения и закрывается без сохранения изменений.
- VBA-макросы отключены; внешние ссылки при открытии не обновляются. Используйте
  самодостаточный XLSX: внешние подключения, пароли и интерактивные запросы не поддерживаются.
- Текст не растрируется. После вставки сравнивается извлечённый текст всех страниц до и после.
- Запоминаются путь к картинке и размер (в `%LOCALAPPDATA%\ExcelSignaturePDF`).
  Файлы обрабатываются локально, сервер не используется.

## Если результат выглядит неправильно

- Лишние пустые страницы: проверьте Ctrl+End в Excel. Иногда UsedRange включает давно
  очищенные, но всё ещё отформатированные строки. Задайте корректную область печати и включите флажок.
- Текст слишком мелкий: выберите альбомную ориентацию или уменьшите число печатаемых столбцов.
- Ошибка занятого места: проверьте нижние колонтитулы и рисунки.
- Ошибка записи: закройте PDF в просмотрщике, который блокирует файл, и повторите.
- Зависший экспорт: проверьте окна Excel (запрос пароля, подключения, защищённый просмотр).
  В первой версии тайм-аут для COM-вызова не реализован.

## Код

- `app.py` — окно tkinter, фоновый экспорт, предпросмотр и сохранение.
- `converter.py` — отдельный процесс Excel через COM, экспорт, вставка картинки и проверка текста.
- `test_pdf.py` — проверки сохранности текста, количества страниц и отказа при перекрытии.

Excel не установлен в среде разработки: реальный COM-экспорт и Windows GUI нужно проверить
на вашем компьютере с настоящим шаблоном. PDF-этап проверен отдельно на тестовых документах.
Перед первым рабочим использованием обязательно проверьте короткую и длинную таблицу.

Зависимость PyMuPDF распространяется по AGPL или коммерческой лицензии. Перед распространением
закрытого приложения проверьте условия; на этапе прототипа отдельный EXE не собирается.
